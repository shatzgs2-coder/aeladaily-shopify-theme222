# AELA Daily Shopify Theme

## Wabi-Sabi Design — OS 2.0 Compatible Shopify Theme

### Theme Structure (45 files)
- **layout/**: theme.liquid (core layout)
- **templates/**: 12 JSON templates (index, product, collection, cart, page, 404, search, etc.)
- **sections/**: 17 Liquid sections (all with schema blocks)
- **snippets/**: 3 reusable snippets (product-card, cart-drawer, responsive-image)
- **assets/**: 11 CSS + JS files (base.css, custom.css, custom.js, vendor.js + section overrides)
- **config/**: settings_schema.json, settings_data.json
- **locales/**: default.json

## How to Import into Shopify
1. Go to **Online Store > Themes** in your Shopify admin
2. Click **Add theme > Upload .zip file**
3. Select `aeladaily-shopify-theme-v3.zip` from this repository's releases
4. Click **Upload**
5. Once uploaded, click **Customize** to preview your store

## Design System
- Colors: #FAFAF7 / #F2EFE8 / #E8E4DD / #8B6F47 / #1F1B16
- Typography: Noto Serif JP (headings) + Inter (body)
- Style: Wabi-sabi / Minimalist / Natural
